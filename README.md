# Novora – Digital Campus Portal
“A new era for digital campus management.”

Novora is a comprehensive digital platform designed to streamline campus operations. It offers features like student and staff management, notice boards, hostel requests, complaints, and lost & found tracking, all within a secure and user-friendly interface.

## 🚀 Features

- **User Authentication**: Secure login system with JWT-based authentication.
- **Role-Based Access**: Differentiated access for students, staff, and administrators.
- **Notice Board**: Centralized location for posting and viewing campus notices.
- **Complaints System**: Allows students and staff to file and track complaints.
- **Hostel Requests**: Manage and process hostel accommodation requests.
- **Lost & Found**: Track and report lost or found items on campus.

## 🛠 Tech Stack

- **Frontend**: React.js, React Router
- **Backend**: Node.js, Express.js
- **Database**: MySQL
- **Authentication**: JWT, bcryptjs
- **Email Service**: Nodemailer for email notifications
